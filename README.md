# Гастро-Терем · Асташово · 8–11 октября 2026

Лендинг выезда в Лесной терем Асташово. Одна страница без сборки и зависимостей:
`index.html` со встроенными стилями и скриптом.

**Сайт:** https://sorvalliny.github.io/astashovo/

Страница закрыта от поисковиков через `noindex, nofollow` — ссылка расходится
только по своим. Публикуется из ветки `main`, деплой идёт автоматически при пуше.

## Настройка перед отправкой участникам

В `index.html` найдите блок в начале `<script>`:

```js
var TG_HANDLE = "";   // телеграм-логин без «@»
var PAY_URL   = "";   // ссылка на оплату (СБП или банк)
```

- `TG_HANDLE` пустой — кнопка только копирует текст заявки в буфер.
- `TG_HANDLE` заполнен — появляется кнопка «Отправить заявку в Телеграм»,
  она открывает чат с уже готовым текстом.
- `PAY_URL` заполнен — рядом встаёт кнопка «Перейти к оплате».

## Как менять цены и комнаты

Все данные в одном массиве `ROOMS` в конце `index.html`. Карточки, выпадающие
списки и расчёт строятся из него — руками править разметку не нужно.

```js
{id:"d2", name:"Домик II", corp:"Домики", seats:5, meta:"свой дом целиком",
 p:{5:45500, 4:48500, 3:53000, 2:62500}},
```

`p` — цена **за человека** при таком числе жильцов в комнате. Общая программа
`PROGRAM = 34500` входит в каждую цену и показывается отдельной строкой под ней.

**Убрать занятую комнату:** удалите её объект из `ROOMS`.

## Экономика

Цена = место в комнате + общая программа 34 500 ₽ на человека.

- Выкуп усадьбы целиком, 3 ночи, всё питание — 376 559 ₽, фикс
- Программа × 25 человек — 825 000 ₽
- Потолок группы — 25 человек: столько одновременно садится за столы

Фикс разложен на комнаты по тому, сколько усадьбы занимает человек: место
в общей комнате домика — 0,8 доли, в номере с удобствами на этаже — 1,3,
с удобствами в номере — 1,6. Занял номер один — платит за него целиком.
Налог на самозанятого 4% зашит внутрь цен.

При полной загрузке сходится: 1 251 500 ₽ сборов − 4% налога = 1 201 440 ₽
против 1 201 559 ₽ расходов.
